# 技術資料3種の視覚ベンチマーク（Gate 3）

元資料（content.yaml / design.yaml）・編集可能 PPTX・PDF の品質を実例で評価し、機械検査の死角を探す。データはすべて架空（`synthetic: true`）。

## 対象と条件

| デッキ | 内容 | 枚数 |
|---|---|---|
| `examples/bench-architecture` | 架空クラウド連携の構成図（区画2・閉路・多段矢印・制御/データの線種）、障害時フロー、比較表 | 6 |
| `examples/bench-table-chart` | 合成データ4方式の比較表（単位・期間）、棒グラフ、折れ線グラフ、条件付き推奨表 | 5 |
| `examples/bench-dense-tech` | ER 図（テキスト表示）、検証 SQL の表、長い和文の箇条書き | 5 |

各デッキを3条件でビルドする: **初期**（design.yaml）、**テーマ変更**（technical-dark、design だけ差し替え）、**文言増加**（要点・本文・注記に補足を追加。数値・表セル・図ラベルは不変）。

```bash
scripts/dev.sh run python3 scripts/benchmark.py
# → build/benchmark/index.html（スライド×条件の before/after 比較）、build/benchmark/metrics.json
```

CI の toolchain ジョブも同じコマンドを実行し、比較ページを artifact として保存する。初期・テーマ変更のどちらかで内容欠落または QA の重大 FAIL があれば終了コード 1。

## 機械検査の死角として見つかり、このベンチマークで直したもの

| 所見 | 原因 | 対応 |
|---|---|---|
| 区画つきの構成図が配置できない（区画に区画外ノードが入る） | 層内等間隔の配置は区画を考慮しない（`LayoutError` で明示停止していた） | 失敗時は区画ごとの横帯に分ける配置へ切り替え。区画名は線と交わらない側へ |
| PDF で長い SQL の表セルが欠落と誤判定 | PDF で折り返されて複数行になり、行の完全一致で照合していた | 12 文字を超える原子値は折返しを許して照合（短い値は行の完全一致のまま） |
| PDF で図のノード名が欠落と誤判定 | PDF の読み順で隣の辺ラベルの文字と混ざる | 図のラベルは単語座標で「自分の枠の中に描かれているか」を照合（より強い検査） |
| 六角形・楕円のノード名が想定外に折り返す | 図形の内側の文字領域の狭さを考慮していなかった | 図形ごとの文字領域の幅で判定し、1行に収まるなら最小 9.5pt まで文字を下げる |
| 本文が枠を超えると、空き領域に収まっていても FAIL | あふれ先の衝突を見ていなかった | あふれが他の文字図形と重なるかスライド下端に達するときだけ FAIL、それ以外は警告 |
| 注記が「Issue」で途切れた | content.yaml の「 #」以降が YAML コメントとして捨てられていた（作成者の誤り、描画は入力に忠実） | `validate.py` が文言中の「 #」を警告。サンプルは引用符で囲む |

## 限界

- 装飾品質の採点は目視による（エージェントの評価）。#10 で人がレビューし、採点を更新する。
- PowerPoint 実機での表示確認は未実施（LibreOffice の PDF/PNG で評価）。#10 の外部検証で確認する。
