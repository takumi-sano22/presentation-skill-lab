# P3-02: ChatGPT生成画像とSVG/HTMLアセットの管理

## 目的
カスタムイラストや図を自由に使いつつ、文字や比較データの編集性を守る。

## 実装
- `assets/` に SVG/PNG と生成元プロンプト/アセットID/ライセンス/更新日時等を保存。
- 必要な場合だけHTML+CSS → SVG/PNG変換。
- 出力解像度・透過・色・比率・アルファ不整合を検査。
- 画像生成はチャットから人間が明示的に指示する運用。

## 完了条件 (DoD)
- [ ] 元アセットと生成物の参照が再現可能
- [ ] 図の中心データを画像として焼き込まない
- [ ] 画像差し替えで本文が変わらない
- [ ] 権利不明素材をCIまたはレビューで検出できる
