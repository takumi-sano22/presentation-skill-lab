# P3-01: ネイティブ技術図とコネクタ自動配置

## 目的
LLMがピクセル座標を直接調整しなくても、読みやすい編集可能な技術構成図を生成する。

## 実装
- nodes/edges/groups を Dagre (MIT) 等で決定論的に配置。
- ネイティブ図形/接続線/ラベルを生成する。
- ノード境界、コネクタ方向、交差を検査。
- ER図の複雑な関係は当面SVGで表現し、元定義を保持する。

## 完了条件 (DoD)
- [ ] 合成アーキ図でノード/線/ラベルの編集ができる
- [ ] ノードの重なり0、接続先不明0
- [ ] 表示と関係の意味が一致する
- [ ] 再生成で位置が不安定にならない
