# P4-01: レイアウト・内容保持・編集性の自動QA

## 目的
日本語の重なり・図形接続不良・PPTXの意図しない画像化を検出する。

## 実装
- 文字サイズ/領域外/オブジェクト重なり/コネクタとノードの交差。
- 文言/表/数値/単位の入力→出力保持検査。
- pptxパッケージから shape/text/table/chart の編集性を検査。
- 誤検知の除外はSlide ID+理由を必須にする。

## 完了条件 (DoD)
- [ ] 意図的に壊したサンプルで各検査がFAIL
- [ ] 正常サンプルで重大FAIL 0
- [ ] 丸め・欠落・意図しない画像化でFAIL
- [ ] 検証結果をCIアーティファクト化

## 前提 / Gate
P2・P3。Gate 3。
